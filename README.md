# 聽見你｜精神疾病家屬的資源與心事

版本：v1.1.2（頁內海報與分類排版）｜2026-11-14，Asia/Taipei

為精神疾病患者之家屬、手足、伴侶與實際照顧者整理全台活動、支持團體、課程與講座。免費資訊入口，報名回原單位；不蒐集病史、不代辦報名。

## 目前可以做什麼

- 支援22縣市、線上／實體／混合、活動類型、日期範圍與報名狀態。
- 搜尋支援台／臺、全半形與常見疾病別名，多詞須同時符合；相關度排序優先標題。
- 手機查活動、閱讀資格與原文證據、本機收藏、下載行事曆。
- 各地來源獨立於活動清單；無結果時誠實說明收錄缺口。
- 資料驗證、同場次去重、來源失敗保留最後有效資料、未確認候選隔離與人工待審報告。

目前快照16個場次（含過去8場），未來8場位於台北、新北與台中；其中台中2場運動課報名已截止。26筆來源／缺口入口涵蓋22縣市，10縣市仍以全國官方名錄作入口。全台可搜尋不代表全台活動已完整收錄；尚無證據完整的近期專門家屬線上場次。費用與名額不明會保留未知，系列費用不當成單場費用。

## 開啟與驗證

直接開啟 `dist/index.html`，頁面內嵌樣式、資料與搜尋程式，可離線使用；原公告連結需網路。手機可用私人 Sites 網址，無需先設定 Cloudflare 或網域。

```bash
python -m unittest discover -s tests -v
node --test tests/test_search.cjs
python src/build.py
```

需要更新原始資料時：

```bash
python src/build.py --refresh
```

不加 `--refresh` 只以既有快照重建，不發出網路請求。離線重建不會刷新任何原公告查核日期。自動解析器目前只支援臺北心衛中心與心生活的設定模板，其他全台資料由人工查核輸入；新發現公告不自動等於可刊登活動。

GitHub Actions 的 Validate 流程會測試並產出預覽；Refresh 流程可手動執行，產出資料、待審報告及預覽供下載。本次未啟用排程或自動發布，靜態網站不會在背景抓取。正式近乎全自動營運仍須建立持續運行及發布驗證，不能把本版視為已完成該目標。
