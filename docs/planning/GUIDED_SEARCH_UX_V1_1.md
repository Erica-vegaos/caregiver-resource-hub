# 聽見你｜先選需要，再看活動
版本：v1.1.0｜2026-11-14（Asia/Taipei）

## 工作流與依賴
templates/index.html：兩題快速入口 → 確認後顯示結果；選項有思覺失調、憂鬱症、躁鬱／雙相、不確定先找支持，以及可跳過的活動地區／參與方式。不預設疾病，不診斷使用者。
src/search.cjs：topicInfo／topicMatch 是獨立於文字搜尋的主題條件，與地區、方式、日期取 AND。只根據標題、摘要、資格、標籤辨識疾病字詞，主辦名稱或附註中的順帶提及不算。
src/build.py：版本與重新建置；dist/index.html 為輸出。無新增外部 API／依賴／疾病資料蒐集。

疾病主題先嚴格匹配，家屬通用支持需使用者主動開啟；開啟後仍不收其他疾病專屬活動，且把通用支持放在相關主題後獨立分組。未知主題不混入這兩類；明確選看全部時才可見。
「不確定，先找支持」直接看家屬通用支持，不將不確定等同全疾病講座。
無結果明說收錄缺口，提供另外開啟通用支持、重新選擇或查看來源，禁止自動放寬。

初步分類是保守的文字規則，不是完整語意或醫療適用性判斷；不能把 UI 分組當作報名資格保證。現有16筆資料為8場未來活動與歷史場次，主要是家屬通用支持；未憑空新增疾病專屬活動。未來投稿的 AI 結果應附可追溯主題證據，另案整合。
選擇只在本頁 state／原生表單中，不進 localStorage、URL、伺服器或分析事件；重新載入重新選。收藏鍵與行事曆 ID 不變。

## Logo 基本 prompt
為台灣公益網站「聽見你」設計 Logo。服務精神疾病患者的家屬與照顧者。名稱有雙重意義：聽見家屬的心聲，也讓家屬聽見生病家人的感受與需要。核心是平等、相互傾聽、理解與連結，不是拯救或單向照顧。風格簡潔、溫暖、成熟、安定，避免醫療機構感與幼兒化。可探索兩個相互回應的抽象形體、留白或對話意象；避免直接用愛心、十字、腦部、悲傷人物及耳朵圖示。主色深森林綠，輔色鼠尾草綠，適配米白網站。先提供三個有明確差異的概念；圖形須在24px仍可辨識，能轉為單色向量。分別提供獨立圖標、圖標加繁體中文「聽見你」橫式組合、透明背景版本；圖標不要嵌入小字。

## 驗證
Python 35項、Node原13項加8項主題反例；內嵌JS語法及移除文字檢查。
必測：思覺選項不混憂鬱／雙相、通用支持明確opt-in、未知不湊數、系列去重與日期行為不變、疾病別名／否定資格、地區方式AND、無結果不放寬、非法topic拒絕。
發布前另以實際分支預覽驗證：初次不列活動、手機320／390px無橫向溢出、主題→空結果→通用支持、重新選擇、篩選開關、整理方式、詳情、收藏，以及桌面。
