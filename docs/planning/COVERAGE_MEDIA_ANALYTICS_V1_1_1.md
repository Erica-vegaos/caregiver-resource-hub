## 最低成本附圖方案
圖片是否由AI生成，不改變取得流程，也不作為轉載授權依據。本版只新增已找到的官方附圖連結，不內嵌或鏡像；保留主辦與公告來源，使用者可自行開啟原圖。已新增運動課兩場、台北康一場、新北康一場，共4個未來場次、3張不同原圖。

未來擷取順序：
1. 同一次公告HTML請求，限正文的img／lazy-src／srcset及明確附件；og:image僅作低可信候選，常是網站logo。排除分享按鈕、追蹤圖示、橫幅與活動花絮。
2. 每個公告先保留主要海報一張的原圖URL、來源頁、來源單位、擷取時間、驗證狀態；系列多場共用一張，不重複處理。其他圖放來源連結。
3. 公告有完整文字就用文字抽取，不對每張海報OCR、不每次叫AI。只有必要欄位僅存在圖片時，按URL＋內容hash快取OCR結果；圖改了才重跑。日期／資格矛盾則留待補證，不拿OCR結果直接覆蓋。
4. 擷取HTTP帶timeout／大小／MIME／redirect與來源白名單限制；持續更新時使用ETag／Last-Modified及有限正文檢查，URL沒變不保證內容沒變。
5. 確認有可使用的授權／機構提供原圖後，才另外考慮本地壓縮縮圖與點擊放大。預設仍提供原公告連結；壞圖不阻擋文字卡片。
6. Facebook／IG等登入、反爬與限權來源先留原貼文連結，讓單位投稿公開公告網址／可分享圖片；不為它們維護瀏覽器爬蟲叢集。

普通HTML＋圖片連結路徑不呼叫模型，模型token成本為0；不代表流量或主機有無限免費額度。OCR例外與圖片托管費需依實際方案評估。本輪未建立每日爬圖／OCR／鏡像服務。

## 更正、申訴與下架
公開信箱 ericaxvega@hotmail.com。網站有聯絡區與活動詳情mail-to，預填活動ID／名稱／原公告，要求說明需處理內容與原因；不自動寄信，不要求初次提供身分證件／病歷，不承諾尚無人力支持的處理時限。
信箱由Erica收件；一般投稿自動刊登的方向不變，權利爭議是例外處理。不能看到匿名信就自動移除別人的活動。
後續處理：收件→核對對應活動／內容／來源或權利關係→決定更正、暫時隱藏或移除→記錄原因與結果。可以只移除圖片而保留必要活動事實。
真正下架時須把活動ID／來源URL／媒體hash記入持久排除紀錄，refresh與投稿兩條入口都遵守，避免下次抓取重新上架；縮圖／快取也需一起處理。本版先完成聯絡入口，未建自動信件讀取與排除佇列。

## 統計狀態與使用者需做的事
已在既有Cloudflare帳號建立 caring.ecp0.com 的免費Web Analytics站點；JS只在正式hostname載入，不記錄需求、疾病、搜尋文字或收藏。安裝所需token是公開beacon識別，不是管理API key。
只先統計瀏覽、造訪、來源與裝置，不做Cookie或個人持久識別。Visits不是不重複人數，不能當成功報名；沒有回補過去的統計。
自家事件計數（完成搜尋／零結果／詳情／外連）仍待持久接收端：只接受固定event enum，直接每日聚合，不接收query、topic、event_id、地區或任意屬性，不做個人軌跡。未接收成功前不放只有送出端的假埋碼。
使用者目前不需建立新帳號、購買服務、貼程式碼或提供密碼。後續只有需要本人登入／授權或付費決定才交接；資料儀表板在Cloudflare帳號內查看，不公開對外。
