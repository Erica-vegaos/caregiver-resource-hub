# 台灣照顧者資源來源盤點

版本：v0.1｜研究與查核日期：2026-11-12（Asia/Taipei）

本表是來源研究，不是即時可報名清單。調查 10 個發布來源／入口，涉及 9 個網域；S10 是 S03 的歷史轉載，**不是第十個獨立活動供應單位**。另檢視一個醫院入口，但未取得符合範圍的活動，不納入優先名單。活動範例是本輪查得的近期或歷史樣本，不宣稱為各單位最新一則。

## 證據分級與共同限制

- **S（搜尋可見）**：搜尋結果有摘要；不能當作原站目前內容。
- **O（開啟成功）**：本輪以網頁閱讀工具開啟原網址並讀到正文；工具可能使用索引／快取，不能據此宣稱 GitHub runner 可以直接擷取。
- **F（下載成功）**：本機 HTTP 取得預期格式的實際位元組；HTTP 200 驗證頁不算。
- **X（欄位擷取驗證）**：本機解析後核對部分關鍵欄位；不代表完整事件解析、長期穩定或授權已驗證。
- **失敗**：保留 HTTP、解析或依賴錯誤，不以更換身分、解驗證或登入方式繞過。

所有下列來源：未建立帳號、未提交報名表、未聯繫單位；未測得可投入使用的活動 API 或 RSS。除特別說明外，API／RSS／JSON-LD／資料下載、robots 與再利用條款均為**未確認**，不是「不存在」。未全面掃描網站，也沒有猜 endpoint 逐一探測。上線前應確認擷取與摘要利用條件；可讀取不等於可全文轉載。

## API／RSS／結構化資料的查證邊界

S01/S05 實際 HTML 掃描未見 `link` 的 RSS/Atom 宣告及 `application/ld+json`，不排除其他頁面提供 feed。S03、S01、家總的定向 RSS/API 搜尋沒有驗證到可用活動介面。S02/S04/S06/S08/S09/S10 未完成全站 feed、開放資料目錄或 API 文件盤查。S09 公開日曆只開到空白閱讀結果，未猜測 ICS URL。所有候選 API/RSS 都不可寫進 MVP 已可用來源名單；未來若單位提供，須測回應格式、更新覆蓋範圍、日期／取消同步與利用授權。

公開社群貼文：S06 明確指向粉專，但本輪沒有測得穩定公開 feed；登入後社群、私人 LINE 群、聊天內容全部不收集。公開貼文也不自動等於允許自動擷取。替代順序：正式網站公告 → 單位公開檔／提交 → 人工必要事實摘要與原文連結。

## 優先順序與待補證據

1. **先試 S01、S05**：已通過部分 HTML 擷取；仍須完成利用條件、列表發現、重複執行測試。
2. **再試 S02、S08**：表格／固定欄位有潛力；前者相關性及狀態陳舊，後者轉貼去重及日期矛盾是必要驗收案例。

4. **S09 選擇性；S10 只作離線壓力測試**：防止一般親職、病友限定、專業進修及去年海報擠進家屬清單。

版本差異：v0.1 首次建立；包含來源盤點、部分成功及失敗實驗，不包含網站、排程、爬蟲或已發布活動資料。
