## 重要限制與待辦

1. 自動更新仍是手動命令的種子頁刷新；沒有完整列表翻頁、新活動全自動解析或取消公告跨頁串連。
2. 第一版所有活動皆為研究候選；未完成來源再利用條件確認，不代表可正式公開營運。HTML 自行開啟不會刷新資料。
3. 費用未確認、名額未知，維持 null／unknown，不算已可報名。來源提供受理期間或報名鈕也不保證尚有名額。
4. 兩筆人工來源來自官方頁面閱讀工具的正文核對；不是本機 HTTP 成功，不可計入兩個 adapter 的穩定性。
5. 未找到符合條件的線上未來活動，選線上時顯示無符合結果，不放假資料；S05 電話服務的資料也不是每次建置自動刷新。
6. JSON 是主資料，尚未實作 SQLite、正式人工核准介面、完整衝突解決或進階模糊去重。
7. 行事曆只代表個人時間規劃，不代表已報名；瀏覽器受限時 localStorage 可能不可用，介面會提示暫存。
8. 公開全文及海報未保存；只有必要欄位與短證據。來源文字不執行，HTML 文字與內嵌 JSON 經跳脫；未做正式安全稽核。
9. GitHub 前次寫入被 integration 權限擋住，沒有藉由替代憑證繞過，也不宣稱本輪已同步遠端。
